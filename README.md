# JobPair - 高性能计算平台任务管理脚本

本项目提供了一套完整的任务管理脚本，用于在高性能计算平台上创建、运行和管理相互监督的作业任务。

## 功能概述

### 1. 核心脚本功能

**jtest.sh** - 任务测试脚本
- 提交作业任务到高性能计算平台
- 启动 jjob1.txt 作业
- 保存作业ID到 job_id.txt 文件中

**jclear.sh** - 作业清理脚本  
- 清理所有相关的 jjob1 和 jjob2 作业
- 清理作业ID文件(job_id.txt)和数据文件(jdata_*)
- 不显示不必要的错误信息

**jjob1.txt** - 作业1脚本
- 执行核心任务逻辑，包含死循环计数器
- 每秒递增计数器并写入 jdata_*.txt 文件（当 DEBUG=1 时）
- 每20秒后开始检测，每3秒检测一次 jjob2 作业状态
- 当检测到 jjob2 作业不存在或处于 EXIT 状态时，立即启动它
- 自动记录详细日志到 jjobs.log 文件（当 DEBUG=1 时）

**jjob2.txt** - 作业2脚本
- 执行核心任务逻辑，包含死循环计数器
- 每秒递增计数器并写入 jdata_*.txt 文件（当 DEBUG=1 时）
- 每20秒后开始检测，每3秒检测一次 jjob1 作业状态
- 当检测到 jjob1 作业不存在或处于 EXIT 状态时，立即启动它
- 自动记录详细日志到 jjobs.log 文件（当 DEBUG=1 时）

### 2. 可配置参数

所有脚本都支持以下可配置参数：

**DEBUG模式**：
- DEBUG=1：启用调试模式（生成日志文件和数据文件）
- DEBUG=0：禁用调试模式（不生成日志文件和数据文件）

**检测参数**：
- INITIAL_DELAY：初始延迟时间（秒），默认20秒
- CHECK_INTERVAL：检测间隔（秒），默认3秒

### 3. 自动化功能

**作业互为监督**：
- jjob1 和 jjob2 互为监督，任何一个停止都会被另一个立即启动
- 支持作业 EXIT 状态的自动清理和重启

**智能清理**：
- 当检测到作业处于 EXIT 状态时，会先清理作业，然后立即重启
- 所有清理操作通过作业管理系统进行，保证系统稳定性

## 使用方法

### 启动任务：
```bash
./jtest.sh
```

### 清理任务：
```bash
./jclear.sh
```

## 文件说明

- **jtest.sh**：启动作业的入口脚本
- **jclear.sh**：清理所有相关作业的脚本  
- **jjob1.txt**：主任务脚本1
- **jjob2.txt**：主任务脚本2
- **jjobs.log**：作业日志文件（当 DEBUG=1 时生成）
- **jdata_*.txt**：任务数据文件（当 DEBUG=1 时生成）
- **job_id.txt**：作业ID文件

所有脚本都具有执行权限，可以直接运行。
